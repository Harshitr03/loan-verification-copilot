# P6 — Frontend: 3 Role Dashboards (Module G + C/D/E UI) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the React + Vite + TypeScript frontend — login and three role-routed dashboards (Data Operator upload+summary; Reviewer queue+detail drawer+AI panel+resolve/verify; Data Consumer verified grid+quality score+audit viewer+export) — against the P1–P5 API, with component tests and a Playwright smoke of the §15 demo flow.

**Architecture:** Vite SPA. `src/api` typed client (fetch + JWT from an auth store), TanStack Query for server state, TanStack Table for the data grids, Tailwind + shadcn/ui for the fintech-dense UI. Role-based routing: after login the JWT `role` picks the home dashboard. Design follows the `frontend-design` skill (invoke it before building UI).

**Tech Stack:** React 18, Vite, TypeScript, Tailwind CSS, shadcn/ui, TanStack Query + Table, react-router, Vitest + React Testing Library, Playwright.

**Spec:** parent §3 (roles/permissions), §8 (Module C/D UI), §10 (dashboards), §15 (demo flow). Depends on **P1–P5 API green**. Roadmap P6.

## Global Constraints

- **Role permissions (spec §3):** operator = upload/validate/lineage; reviewer = queue/AI/edit/approve/verify; consumer = verified reads/export/audit. The UI hides actions a role can't perform (defense-in-depth; the API already gates).
- **AI rendered separately (spec §8/§9):** AI suggestions appear in a distinct panel; applying one is an explicit reviewer action (calls `resolve` with `action:"edit"`), never automatic.
- **Env-driven API base:** `VITE_API_BASE` (default `http://localhost:8000`); the P7 compose sets it.
- **Login is form-encoded (finding #7):** `POST /auth/login` sends `application/x-www-form-urlencoded` `username`/`password` (matching the backend's `OAuth2PasswordRequestForm`), not JSON. The rest of the API is JSON.
- **Design intent:** invoke the `frontend-design` skill before T2; avoid templated defaults; data-dense, calm fintech aesthetic; light+dark.
- **No secrets in the bundle;** JWT lives in memory + `sessionStorage`, cleared on logout.
